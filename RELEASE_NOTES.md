First release.

- A Settings button on the new game screen on the ferry opens the game's "Settings per Save Game" (colour schemes and difficulty), so you can set them before the game starts.
- The rider on the ferry changes at once when you switch or edit a skin or hair colour scheme.

Install: extract the zip into the game folder, so that you have `BepInEx\plugins\NewGameSettings\NewGameSettings.dll`. Needs BepInEx 6 bleeding edge build 793 (IL2CPP). Made for game version 1.0.5.
